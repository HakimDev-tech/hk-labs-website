# HK Labs — Official website

Public marketing website and portfolio for HK Labs, an independent frontend development studio.

## Stack
- Next.js 15 App Router
- React 19 and TypeScript
- Responsive custom CSS
- Lucide icons
- Netlify hosting with the Next.js runtime adapter

## Getting started
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Quality checks
```bash
npm run typecheck
npm run lint
npm run build
```

## SEO
- Canonical URL and metadata base: https://hk-labs.netlify.app
- Dynamic XML sitemap at `/sitemap.xml`
- Crawler rules at `/robots.txt`
