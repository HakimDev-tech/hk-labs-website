# HK Labs — Service offer

## Positioning
Independent frontend development studio for small businesses and digital agencies. Focus: targeted frontend fixes, existing website improvements and landing page rebuilds.

## Launch offers
| Offer | Starting price | Scope |
|---|---:|---|
| Frontend Fix | $79 | 1–3 clearly defined UI or responsive issues |
| Website Improvement | $129 | One focused page improvement |
| Landing Page Rebuild | $299 | One landing page, scoped sections and responsive implementation |

These are entry-level starting prices, not unconditional fixed quotes. Complexity, content readiness, integrations and codebase condition can change the quote.

## Delivery rules
- Written communication; no calls required.
- Written scope and acceptance criteria before work starts.
- Two revision rounds within the agreed scope.
- Seven-day bug-fix window for defects in delivered scope; excludes new features and third-party changes.
- Projects below $150: 100% upfront.
- Projects at or above $150: 50% upfront, 50% before final handover.
- No production work begins before the agreed initial payment.

Every proposal must state deliverables, exclusions, timeline, dependencies, price, currency, payment milestones, revision rules and handover format.
